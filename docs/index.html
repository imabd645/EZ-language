EZ Language Documentation

A modern numerpreted programming language designed for simplicity and readability.

What is EZ?

EZ is a modern numerpreted programming language built in C++17. It is designed to feel natural and readable — closer to plain English than traditional languages. EZ is ideal for learners, scripting, building small web APIs, and working with local databases without any boilerplate.

EZ combines the best of both worlds: the simplicity of Python with the expressiveness of modern scripting languages. Whether you're a beginner learning your first programming language or an experienced developer looking for a lightweight tool for quick scripts, EZ provides an numuitive environment that gets out of your way.

Simple Syntax

No semicolons, no curly braces. Just clean, readable code.

Built-in SQLite

Database operations made simple with native SQL support.

Web Server

Build APIs and web apps without external frameworks.

Package Manager

Install and share packages with the built-in ez command.

OOP Support

Full object-oriented programming with models and inheritance.

Single Executable

Just download and run. No complex setup required.

Why EZ?

  • No semicolons, no curly braces clutter — EZ uses indentation and English-like keywords for a cleaner look
  • English-like keywords — Use when, repeat, get, out instead of cryptic symbols
  • Built-in SQLite database support — Work with databases without installing drivers or writing boilerplate
  • Built-in web server — No frameworks needed to build REST APIs or simple web services
  • Package manager included — Install community packages with a simple ez install command
  • Single executable — Just download and run. All dependencies bundled.

Design Philosophy

"Programming should read like instructions you'd give a person, not commands you'd give a machine."

EZ was created with the belief that programming languages should prioritize human readability. Every design decision — from keyword choice to syntax structure — serves this goal. The language is deliberately minimal, including only essential features to reduce cognitive load while remaining powerful enough for real-world tasks.

Getting Started

Prerequisites

Before installing EZ, ensure you have:

  • Windows OS — EZ currently supports Windows (Linux/Mac support coming soon)
  • No additional installs needed — All required DLLs are bundled with the executable

Installation

Follow these steps to install EZ on your Windows system:

  1. Download ez.exe and all .dll files from the GitHub releases page
  2. Create a permanent folder for EZ, for example: C:\ezlang
  3. Place all downloaded files in this folder
  4. Add the folder to your system PATH (see instructions below)

Adding to PATH

To use EZ from any command prompt window, add it to your system PATH:

  1. Press Win + S and search "Environment Variables"
  2. Click "Edit the system environment variables"
  3. Click the "Environment Variables" button
  4. Under "System variables", find "Path" and click "Edit"
  5. Click "New" and enter: C:\ezlang (or your chosen folder)
  6. Click "OK" on all dialogs to save
  7. Restart your terminal/command prompt

After adding to PATH, you can run ez from any directory.

Running Your First Script

To run an EZ script, use the following command:

Terminal 
ez path/to/yourscript.ez

You can also run EZ without arguments to enter numeractive mode:

Terminal 
ez

Hello World Example

Create a file named hello.ez with the following content:

EZ 
out("Hello, World!")

Run it:

Terminal 
ez hello.ez

Output:

Output 
Hello, World!

Language Basics

Comments

Comments in EZ start with the # character and skip to the end of the line:

EZ 
# This is a single-line comment
out("Hello")  # This is an inline comment

Currently, EZ only supports single-line comments. Multi-line comments can be simulated by using multiple single-line comments.

Variables

Variables in EZ are declared using the let keyword. EZ is dynamically typed, so you don't need to specify the type:

EZ 
let name = "Alice"
let age = 25
let score = 98.5
let active = true
let items = [1, 2, 3]
let nothing = nil

Variable names must start with a letter or underscore and can contain letters, numbers, and underscores. EZ uses snake_case by convention.

Data Types

EZ supports the following data types:

You can check the type of a value using the type() function:

EZ 
let x = 42
out(type(x))  # Number

let y = "hello"
out(type(y))  # String

String Operations

Strings in EZ support concatenation using the + operator:

EZ 
let first = "Hello"
let second = "World"
let greeting = first + ", " + second + "!"
out(greeting)  # Hello, World!

Use the len() function to givethe length of a string:

EZ 
let text = "Hello, World!"
out(len(text))  # 13

Control Flow

when / other / other (if/elif/else)

EZ uses English-like keywords for conditional statements. Use when for if, other for else if, and other for else:

EZ 
let age = 20

when age >= 18 {
    out("Adult")
} other age >= 13 {
    out("Teenager")
} other {
    out("Child")
}

You can also use and and or for compound conditions:

EZ 
let score = 85
let passed = true

when score >= 80 and passed {
    out("Excellent work!")
}

repeat (loops)

EZ supports two styles of loops with the repeat keyword: while-style and for-style.

While-style loops

EZ 
let i = 0
repeat i < 5 {
    out(i)
    i = i + 1
}

For-style loops (iterating over arrays)

EZ 
repeat item in ["apple", "banana", "cherry"] {
    out(item)
}

Looping with index

EZ 
let fruits = ["apple", "banana", "cherry"]
let i = 0
repeat i < len(fruits) {
    out(i + ": " + fruits[i])
    i = i + 1
}

escape and skip

Use escape to exit a loop early and skip to skip to the next iteration:

EZ 
let i = 0
repeat i < 10 {
    i = i + 1
    when i == 5 {
        skip  # Skip number 5
    }
    when i == 8 {
        escape  # Stop at 8
    }
    out(i)
}

Output: 1, 2, 3, 4, 6, 7

Functions (Tasks)

Defining a task

Functions in EZ are called tasks. Define a task using the task keyword:

EZ 
task greet() {
    out("Hello from EZ!")
}

Parameters

Tasks can accept parameters:

EZ 
task greet(name) {
    out("Hello, " + name + "!")
}

greet("Alice")  # Hello, Alice!
greet("Bob")    # Hello, Bob!

Multiple parameters are separated by commas:

EZ 
task greet(first, last) {
    out("Hello, " + first + " " + last + "!")
}

greet("John", "Doe")

Return values (get)

Use the get keyword to return a value from a task:

EZ 
task add(a, b) {
    givea + b
}

let result = add(3, 4)
out(result)   # 7

You can return any type of value:

EZ 
task make_person(name, age) {
    let person = {
        "name": name,
        "age": age
    }
    giveperson
}

let p = make_person("Alice", 25)
out(p.name)   # Alice

Scope

Variables defined inside a task are local to that task. Variables defined outside are global:

EZ 
let global_var = "I am global"

task demo() {
    let local_var = "I am local"
    out(global_var)   # Works: I am global
    out(local_var)    # Works: I am local
}

demo()
out(global_var)       # Works
# out(local_var)      # Error: local_var not defined

Object-Oriented Programming

Defining a model

In EZ, classes are called models. Define a model using the model keyword:

EZ 
model Animal {
    task init(name) {
        self.name = name
    }
}

let dog = Animal("Rex")
out(dog.name)

Constructors

The init task is the constructor, called when creating a new instance:

EZ 
model Person {
    task init(first_name, last_name, age) {
        self.first_name = first_name
        self.last_name = last_name
        self.age = age
    }
}

let person = Person("John", "Doe", 30)
out(person.first_name + " " + person.last_name)

Attributes

Attributes are variables that belong to a model instance. Access them using self.attribute_name inside the model, and instance.attribute_name outside:

EZ 
model Car {
    task init(make, model, year) {
        self.make = make
        self.model = model
        self.year = year
        self.odometer = 0
    }
}

let my_car = Car("Toyota", "Camry", 2023)
out(my_car.make)      # Toyota
out(my_car.odometer)  # 0

Member tasks (methods)

Tasks defined inside a model are called member tasks or methods. They can access and modify the instance's attributes:

EZ 
model BankAccount {
    task init(owner, balance) {
        self.owner = owner
        self.balance = balance
    }

    task deposit(amount) {
        self.balance = self.balance + amount
        out(self.owner + " deposited " + amount)
    }

    task get_balance() {
        giveself.balance
    }
}

let account = BankAccount("Alice", 100)
account.deposit(50)
out(account.get_balance())  # 150

Creating instances

Create an instance by calling the model name as a function with the constructor arguments:

EZ 
model Dog {
    task init(name, breed) {
        self.name = name
        self.breed = breed
    }

    task bark() {
        out(self.name + " says: Woof!")
    }
}

let my_dog = Dog("Rex", "German Shepherd")
my_dog.bark()  # Rex says: Woof!

Accessing members

Use dot notation to access attributes and methods:

EZ 
model Student {
    task init(name) {
        self.name = name
        self.grades = []
    }

    task add_grade(score) {
        self.grades.push(score)
    }
}

let student = Student("Alice")
out(student.name)       # Access attribute: Alice
student.add_grade(95)     # Call method
out(student.grades)     # Access array attribute: [95]

Arrays & Collections

Creating arrays

Arrays in EZ are created using square brackets with comma-separated values:

EZ 
let empty = []
let numbers = [1, 2, 3, 4, 5]
let fruits = ["apple", "banana", "cherry"]
let mixed = [1, "hello", true, nil]
let nested = [[1, 2], [3, 4], [5, 6]]

Indexing

Access array elements using zero-based indexing with square brackets:

EZ 
let fruits = ["apple", "banana", "cherry", "date"]
out(fruits[0])    # apple
out(fruits[1])    # banana
out(fruits[3])    # date

# Modify elements
fruits[1] = "blueberry"
out(fruits)       # ["apple", "blueberry", "cherry", "date"]

Use negative indices to access elements from the end:

EZ 
let items = ["a", "b", "c", "d"]
out(items[-1])   # d (last element)
out(items[-2])   # c (second to last)

Looping over arrays

Use the repeat...in syntax to iterate over array elements:

EZ 
let colors = ["red", "green", "blue"]
repeat color in colors {
    out("Color: " + color)
}

For index-based iteration:

EZ 
let scores = [85, 92, 78, 96]
let i = 0
repeat i < len(scores) {
    out("Score " + (i + 1) + ": " + scores[i])
    i = i + 1
}

Database (SQLite)

Connecting to a database

EZ has built-in SQLite support. Open a database using dbOpen:

EZ 
# Open or create a database file
let db = dbOpen("myapp.db")

Creating tables

Use dbExec to execute SQL statements:

EZ 
let db = dbOpen("myapp.db")

# Create a table
dbExec(db, "CREATE TABLE IF NOT EXISTS users (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    email TEXT,
    age INTEGER
)")

Inserting data

EZ 
# Insert data
dbExec(db, "INSERT INTO users (name, email, age) VALUES (?, ?, ?)",
    ["Alice", "alice@example.com", 25])

dbExec(db, "INSERT INTO users (name, email, age) VALUES (?, ?, ?)",
    ["Bob", "bob@example.com", 30])

Querying data

Use dbQuery to fetch data. It returns an array of rows:

EZ 
# Query all users
let users = dbQuery(db, "SELECT * FROM users")
repeat user in users {
    out(user.name + " - " + user.email)
}

# Query with condition
let adults = dbQuery(db, "SELECT * FROM users WHERE age >= ?", [18])
out("Found " + len(adults) + " adults")

Parameterised queries

Always use parameterised queries (with ? placeholders) to prevent SQL injection:

EZ 
let user_input = input("Enter name: ")

# Safe - uses parameters
let result = dbQuery(db, 
    "SELECT * FROM users WHERE name = ?",
    [user_input])

# Never concatenate user input directly numo SQL!
# Unsafe - DO NOT DO THIS:
# dbQuery(db, "SELECT * FROM users WHERE name = '" + user_input + "'")

Closing connection

Always close the database when done:

EZ 
let db = dbOpen("myapp.db")

# ... do database operations ...

dbClose(db)
out("Database closed")

Web Server

Starting a server

EZ includes a built-in web server. Create and start a server with web_create and web_start:

EZ 
# Create a server on port 8080
let server = web_create(8080)

out("Server starting on http://localhost:8080")
web_start(server)

# Server runs until stopped (Ctrl+C)

Defining routes

Use web_route to define URL routes:

EZ 
let server = web_create(8080)

# Route handler task
task home_handler(req) {
    giveweb_response("Welcome to EZ!", 200)
}

# Register routes
web_route(server, "/", home_handler)
web_route(server, "/hello", task(req) {
    giveweb_response("Hello, World!", 200)
})

web_start(server)

Handling requests

The request object contains information about the HTTP request:

EZ 
web_route(server, "/user/:id", task(req) {
    # req.path - full path
    # req.params - URL parameters (e.g., id)
    # req.query - query string parameters
    # req.body - request body
    # req.headers - request headers
    
    let user_id = req.params.id
    out("Request for user: " + user_id)
    
    giveweb_response("User: " + user_id, 200)
})

Sending responses

Use web_response to create HTTP responses:

EZ 
# Simple text response
giveweb_response("Hello", 200)

# JSON response
let data = {
    "name": "Alice",
    "age": 25
}
giveweb_response(data, 200)

# Custom headers
let headers = {
    "Content-Type": "text/html"
}
giveweb_response("
Hello
", 200, headers)

Full API example

Here's a complete REST API with database numegration:

EZ 
# API Example with SQLite
let db = dbOpen("api.db")

# Create table
dbExec(db, "CREATE TABLE IF NOT EXISTS items (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT,
    value INTEGER
)")

let server = web_create(8080)

# GET all items
web_route(server, "/items", task(req) {
    let items = dbQuery(db, "SELECT * FROM items")
    giveweb_response(items, 200)
})

# GET single item
web_route(server, "/items/:id", task(req) {
    let items = dbQuery(db, 
        "SELECT * FROM items WHERE id = ?",
        [req.params.id])
    when len(items) > 0 {
        giveweb_response(items[0], 200)
    } other {
        giveweb_response({"error": "Not found"}, 404)
    }
})

# POST new item
web_route(server, "/items", task(req) {
    let name = req.body.name
    let value = req.body.value
    dbExec(db,
        "INSERT INTO items (name, value) VALUES (?, ?)",
        [name, value])
    giveweb_response({"created": true}, 201)
})

out("API server on http://localhost:8080")
out("Try: curl http://localhost:8080/items")
web_start(server)

EZ includes a built-in package manager. Install packages from the command line:

Terminal 
# Install a package
ez install math

ez install collections http json

Using installed packages

Import packages in your EZ code with the import keyword:

EZ 
# Import installed packages
use math

out(math.sqrt(144))

Installed packages are stored in C:/ezlib. This directory contains:

You can also manually install packages by placing files in this directory.

Examples

Calculator

An numeractive calculator using input() and when statements:

EZ 
# Simple Calculator
out("=== EZ Calculator ===")

let running = true
repeat running {
    out("\nOperations: +  -  *  /  **  exit")
    let op = input("Enter operation: ")
    
    when op == "exit" {
        running = false
    } other op == "+" {
        let a = num(input("First number: "))
        let b = num(input("Second number: "))
        out("Result: " + (a + b))
    } other op == "-" {
        let a = num(input("First number: "))
        let b = num(input("Second number: "))
        out("Result: " + (a - b))
    } other op == "*" {
        let a = num(input("First number: "))
        let b = num(input("Second number: "))
        out("Result: " + (a * b))
    } other op == "/" {
        let a = num(input("First number: "))
        let b = num(input("Second number: "))
        when b == 0 {
            out("Error: Cannot divide by zero")
        } other {
            out("Result: " + (a / b))
        }
    } other op == "**" {
        let a = num(input("Base: "))
        let b = num(input("Exponent: "))
        out("Result: " + (a ** b))
    } other {
        out("Unknown operation")
    }
}

out("Goodbye!")

Todo list (with SQLite)

A persistent todo list application using SQLite:

EZ 
# Todo List with SQLite
let db = dbOpen("todos.db")

# Create table
dbExec(db, "CREATE TABLE IF NOT EXISTS todos (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    task TEXT,
    completed INTEGER DEFAULT 0
)")

task add_todo(task_text) {
    dbExec(db, 
        "INSERT INTO todos (task) VALUES (?)",
        [task_text])
    out("Added: " + task_text)
}

task list_todos() {
    let todos = dbQuery(db, 
        "SELECT * FROM todos WHERE completed = 0")
    out("\n=== Your Todos ===")
    when len(todos) == 0 {
        out("No pending todos!")
    }
    repeat todo in todos {
        out(todo.id + ". " + todo.task)
    }
}

task complete_todo(id) {
    dbExec(db,
        "UPDATE todos SET completed = 1 WHERE id = ?",
        [id])
    out("Completed todo #" + id)
}

task delete_todo(id) {
    dbExec(db,
        "DELETE FROM todos WHERE id = ?",
        [id])
    out("Deleted todo #" + id)
}

# Main loop
let running = true
repeat running {
    out("\n1. Add todo")
    out("2. List todos")
    out("3. Complete todo")
    out("4. Delete todo")
    out("5. Exit")
    
    let choice = input("Choice: ")
    
    when choice == "1" {
        let task = input("Enter task: ")
        add_todo(task)
    } other choice == "2" {
        list_todos()
    } other choice == "3" {
        let id = input("Todo ID: ")
        complete_todo(num(id))
    } other choice == "4" {
        let id = input("Todo ID: ")
        delete_todo(num(id))
    } other choice == "5" {
        running = false
    } other {
        out("Invalid choice")
    }
}

dbClose(db)
out("Goodbye!")

OOP: Bank account model

A complete bank account system using OOP:

EZ 
# Bank Account System
model BankAccount {
    task init(account_number, owner, initial_balance) {
        self.account_number = account_number
        self.owner = owner
        self.balance = initial_balance
        self.transactions = []
        self._log_transaction("Account opened", initial_balance)
    }

    task _log_transaction(type, amount) {
        push(self.transactions, {
            "type": type,
            "amount": amount,
            "balance": self.balance
        })
    }

    task deposit(amount) {
        when amount <= 0 {
            out("Invalid deposit amount")
            givefalse
        }
        self.balance = self.balance + amount
        self._log_transaction("Deposit", amount)
        out("Deposited $" + amount + " to account " + self.account_number)
        givetrue
    }

    task withdraw(amount) {
        when amount <= 0 {
            out("Invalid withdrawal amount")
            givefalse
        }
        when amount > self.balance {
            out("Insufficient funds")
            givefalse
        }
        self.balance = self.balance - amount
        self._log_transaction("Withdrawal", -amount)
        out("Withdrew $" + amount + " from account " + self.account_number)
        givetrue
    }

    task get_balance() {
        giveself.balance
    }

    task get_statement() {
        out("\n=== Statement for " + self.owner + " ===")
        out("Account: " + self.account_number)
        out("Current Balance: $" + self.balance)
        out("\nTransactions:")
        repeat t in self.transactions {
            out("  " + t.type + ": $" + t.amount + " (Balance: $" + t.balance + ")")
        }
    }
}

# Create accounts
let alice_account = BankAccount("ACC001", "Alice", 1000)
let bob_account = BankAccount("ACC002", "Bob", 500)

# Perform transactions
alice_account.deposit(500)
alice_account.withdraw(200)
alice_account.withdraw(2000)  # Should fail (insufficient funds)
alice_account.get_statement()

bob_account.deposit(1000)
bob_account.get_statement()

Comparison with Python/JS

EZ vs Python:

  • EZ uses braces {} for blocks instead of indentation
  • EZ has get instead of return
  • EZ uses when/other/other instead of if/elif/else
  • EZ arrays use [] like Python lists

EZ vs JavaScript:

  • EZ uses let for all variable declarations
  • EZ uses task instead of function
  • EZ uses model instead of class
  • EZ arrays have Python-style negative indexing
